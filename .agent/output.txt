WHAT THE SYSTEM IS
--------------------------------------------------------------------------------
A Weighted Decision Support System (DSS) that recommends an academic stream
(Science / Humanities / Business) to Nigerian SS2 students using an
AHP-SAW multi-criteria decision engine. Inputs: JSS3/SS1 academic scores,
a 48-item RIASEC vocational interest quiz, and a 20-item BFI personality
questionnaire. Output: a ranked stream recommendation with confidence level,
plain-language guidance, AHP weight transparency, and a JAMB O'Level subject
combination validator against a seeded university-course catalog.

STACK (2026-08-06)
  Frontend: React 19 + Vite 5 + TailwindCSS + React Router 6 + Recharts + Axios
  UI:       @arcevo/facet-components + @arcevo/facet-layout + @arcevo/facet-tokens
            (OKLCH tokens, dark-first) — the ONLY UI foundation.
  Backend:  Express 4 + TypeScript (ESM) + Zod validation
  Database: PostgreSQL + Prisma 7 (adapter-pg, generated TS client)
  Engine:   Pure TS modules (AHP, SAW, RIASEC, BFI, confidence, jamb) — no DB/HTTP deps
  Auth:     JWT (7d expiry, bcrypt-12 hashing), role claim on token,
            requireRole guard, pnpm create:admin bootstrap script
            (arc-id/facet-auth is DEFERRED — see Identity decision below)
  Deploy:   Vercel (static client) + server behind reverse proxy (Railway/Cloudflare)

METHODOLOGY DECISIONS RECORDED (2026-08-06) — for the thesis
===============================================================================
  • P0-3e NEUROTICISM: INCLUDED as Emotional Stability (100 − neuroticism).
    Rationale: the FFM grounding (§2.3.3) + Mammadov's meta-analysis (§2.3.4)
    establish that stability predicts capacity to SUSTAIN a demanding stream's
    workload — so the inverse of neuroticism is a legitimate positive driver
    for all three streams. SAW's personality criterion is now the mean of 3
    traits per stream (O+C+ES / O+A+ES / E+C+ES). The raw neuroticismScore
    column stays on PersonalityProfile for the research record. Cite this in
    §3.5.3; algorithmVersion = ahp-saw-v1.1.
  • P0-3b NO FAKE DATA: BFI-less students are NEVER injected neutral
    60/60/60/60 at full weight. Personality weight is renormalized over the
    criteria present, flagged personalitySource: "renormalized".
  • P0-3c CONFIDENCE RESCALE: display CL min-max rescaled to [50, 100] — the
    50% anchor is the "all three streams equal" 1/3 baseline. Documented in
    confidence.ts + saw.ts.
  • P0-3d STREAM TRAIT MAPPING: Science=(O+C)/2 is canonical (saw.ts); the
    schema comment that said Science→O only was stale and is now corrected.
